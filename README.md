## 🤖 My AI-Assisted Engineering Philosophy

AI can help us build faster. Engineering judgment helps us build responsibly.

<p align="center">
  <img src="https://img.shields.io/badge/Understand-01-0EA5E9?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Plan-02-8B5CF6?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Implement-03-10B981?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Test-04-F59E0B?style=for-the-badge"/>
  <img src="https://img.shields.io/badge/Verify-05-EF4444?style=for-the-badge"/>
</p>

My workflow:

1. 🔎 **Understand** — clarify the requirement and expected behaviour.
2. 🧩 **Decompose** — break complex tasks into smaller, testable pieces.
3. 📝 **Contextualise** — give AI coding agents clear instructions, constraints, and project context.
4. 🛠️ **Implement** — build the feature while understanding the generated code.
5. 🧪 **Test** — run tests, investigate errors, and check edge cases.
6. ✅ **Verify** — compare the result against the original requirements.

I'm particularly interested in agentic engineering, reliable AI-generated code, automated testing, and using AI tools to solve real development problems.
